# Event archive

Edit `events.json` to add or update a show on `/events.html`. Entries are sorted newest first and grouped by year. All show information appears on this single page.

Required fields: `slug` (unique identifier, lowercase words separated by hyphens), `title`, `date` (`YYYY-MM-DD`), `venue`, and `city`.

Optional: `videoUrl` adds a “Watch performance” link beneath the show details.
